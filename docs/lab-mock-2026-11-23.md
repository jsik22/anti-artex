# 실험실 실측 3회차: 생성 대본 대량 실행과 행동 신호 (2026-11-23)

## 방법

- **ARTEX 실행 112회(요청 5,669건)**: 최신 변형 두 계열(영문 재배포판 v0.7.0 64회, 원 개발자 계열 v0.3.30 48회)을 가짜 모델로 구동했다. 실행마다 아래 조건을 무작위로 골랐다.
  - 대본 조각 2~5개와 조각 안의 변형 수(로그인 비밀번호 수, 검색 입력 변형, 열거 경로 수, WebFetch 경로)
  - 조각 후보: WebFetch, 로그인·검색 변형, api-recon, 경로 열거, 한 턴 다중 호출, 폼 수집과 발견 보고, 백그라운드 명령, 대화형 셸, nmap, 그리고 v0.7.0 이미지에 든 httpx·katana·ffuf·nuclei·sqlmap·dalfox·헤드리스 브라우저
  - 모델 지연(0초~25초), 모델 오류 주입, 소음 조절(v0.7.0), 기록 프록시(실행의 약 4분의 1)
- **정상 트래픽 30회(출발지 103개, 요청 14,182건)**: 사람 브라우저(사람마다 경로·속도가 다르고 비밀번호를 한두 번 틀림), curl 헬스 체크, API 폴링, 앱 고유 UA 클라이언트, 브라우저 UA로 위장한 정상 수집 스크립트, wget 미러, 링크 점검을 섞었다. 11회는 여러 역할을 한 출발지에 몰아 사무실 NAT를 흉내 냈다.
- 출발지 하나를 단위로 행동 특징을 뽑아 신호마다 걸린 비율을 셌다.
